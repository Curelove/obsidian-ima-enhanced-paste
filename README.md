# IMA Enhanced Paste

一个用于 Obsidian 的 IMA 增强粘贴插件。

本插件读取 IMA 提供的自定义剪贴板内容，将文字、换行、基本格式、颜色、图片、列表、待办、表格和其他可识别结构转换为适合 Obsidian 使用的 Markdown 或 HTML。

## 功能

- 保留从 IMA 复制内容中的换行。
- 支持普通段落与一级至六级标题。
- 支持加粗、斜体、下划线、删除线、链接、字体颜色和背景高亮。
- 支持左对齐、居中、右对齐和两端对齐。
- 支持无序列表、有序列表、待办事项、代码块、引用和分隔线。
- 支持 IMA 表格、文字与图片混合内容。
- 自动下载图片并保存到当前仓库。
- 相同图片再次粘贴时复用已有文件，避免重复下载。
- 支持将纯文字 IMA 内容粘贴到 Obsidian 内联标题。
- 有选中文字时替换选区，没有选中文字时插入光标位置。
- 只在检测到 IMA 自定义剪贴板数据时接管粘贴。
- 支持 HTML 富格式、Markdown 兼容格式和 Markdown 优先格式。
- 支持将当前笔记中的 HTML 转换为 Markdown。
- 支持修复整个仓库中的旧图片链接。
- 支持检查并清理未被引用的插件图片。
- 提供清理 IMA 导出空行占位符的命令。

## 使用方法

1. 在 IMA 中选中需要复制的内容。
2. 按 `Ctrl + C`。
3. 打开 Obsidian 中的 Markdown 笔记。
4. 将光标放在需要插入内容的位置。
5. 按 `Ctrl + V`。

如果剪贴板中包含 IMA 自定义数据，插件会自动处理并插入内容。

如果剪贴板中不包含 IMA 自定义数据，插件不会干预，Obsidian 会继续使用默认粘贴行为。

## 粘贴位置

### 粘贴到正文

IMA 内容粘贴到正文时：

- 有选中文字时，粘贴内容会替换选区；
- 没有选中文字时，内容会插入当前光标位置；
- 文字、换行、标题、列表、待办、引用和代码块会尽量转换；
- 图片会下载到设置中的图片保存目录；
- 表格会根据当前输出格式转换；
- 颜色和背景高亮会在支持的情况下保留。

### 粘贴到内联标题

将纯文字 IMA 内容粘贴到 Obsidian 内联标题时：

- 内容会插入标题输入区域；
- 图片会被忽略；
- 公式、表格、代码块和其他复杂内容不会作为标题内容插入。

Obsidian 内联标题和正文中的 Markdown 标题不是同一个编辑区域。

### 粘贴到笔记属性

粘贴到 Obsidian 笔记属性区域时：

- 本插件不会接管粘贴；
- 内容会交给 Obsidian 默认处理；
- 不会强行将内容写入正文。

## 输出格式

插件提供三种直接粘贴输出格式。

### HTML 富格式

尽量保留颜色、背景高亮、对齐、复杂表格和其他视觉样式。

适合希望尽量保留原始显示效果的情况。

### Markdown 兼容格式

普通格式尽量转换为 Markdown：

```markdown
**加粗文字**
*斜体文字*
~~删除线文字~~
[链接文字](https://example.com)
```

颜色、背景高亮和部分对齐信息无法用标准 Markdown 表达，因此可能被删除。

### Markdown 优先格式

普通格式优先转换为 Markdown。

颜色、背景高亮、下划线、对齐和复杂表格无法完整用 Markdown 表达时，会保留为 HTML。

例如，带颜色的加粗文字会使用类似以下结构：

```html
<span data-rich-paste="1" style="color:#136CE9;"><strong>菜单栏</strong></span>
```

插件不会将 `**`、`*` 或 `~~` 放在颜色标签内部，避免 Obsidian 编辑模式显示多余标记。

## 当前笔记转换

插件可以通过左侧按钮或命令面板，将当前笔记中的部分 HTML 转换为：

- Markdown 兼容格式；
- Markdown 优先格式。

转换前可以显示预计处理的内容，以及可能丢失或继续保留为 HTML 的内容。

### 转换范围

设置中可以选择：

- 仅转换带插件标记的 HTML；
- 转换插件标记和旧版本 HTML；
- 转换当前笔记中所有可识别 HTML。

仅转换带插件标记的内容最安全。

转换旧版本 HTML 时，插件无法完全判断这些内容是否由本插件生成。转换所有可识别 HTML 时，也可能影响手动编写的 HTML。

### 代码内容

为了避免改动代码示例，当前笔记转换时会保持以下内容原样：

- 使用三个反引号包围的整段内容；
- 使用一对反引号包围的短内容。

只有普通正文中的 HTML 会按照当前设置处理。

## 支持的格式

| IMA 格式 | 转换结果 |
| --- | --- |
| 普通文字 | 普通文字 |
| 加粗 | Markdown 加粗或 HTML 加粗 |
| 斜体 | Markdown 斜体或 HTML 斜体 |
| 加粗并斜体 | `***文字***` 或对应 HTML |
| 下划线 | `<u>下划线文字</u>` |
| 删除线 | Markdown 删除线或 HTML 删除线 |
| 字体颜色 | `<span style="color: ...">文字</span>` |
| 背景高亮 | `<mark style="background-color: ...">文字</mark>` |
| 标题 | `# 标题` 至 `###### 标题` |
| 无序列表 | `- 列表内容` |
| 有序列表 | `1. 列表内容` |
| 未完成待办 | `- [ ] 待办内容` |
| 已完成待办 | `- [x] 已完成待办` |
| 分隔线 | `---` |
| 代码块 | Markdown 代码块 |
| 引用 | `> 引用内容` |
| 链接 | Markdown 链接或 HTML 链接 |
| 表格 | Markdown 表格或静态 HTML 表格 |
| 图片 | 下载到本地后插入 |

## 图片

默认情况下，图片会保存到当前仓库根目录下的：

```text
IMA Images
```

也可以在插件设置中修改图片保存目录。

新粘贴的图片会使用仓库内的稳定引用，例如：

```markdown
![[IMA Images/rich-paste-image-e70a1bb2.webp|IMA 图片]]
```

这种引用：

- 不依赖 Obsidian 每次启动时生成的 `app://` 地址；
- 重启 Obsidian 后仍然有效；
- 移动当前笔记到其他文件夹后仍然有效；
- 不会因为输出格式不同而生成不同的图片文件名。

相同图片再次粘贴时，插件会根据图片的稳定地址生成相同文件名，并复用已有文件。

### 修改图片保存目录

修改图片保存目录只会影响以后下载的新图片。

已经存在的图片不会自动移动，已经修复的笔记链接也不会自动改写。因此，修改目录后，旧图片仍然可以继续使用原来的实际路径。

### 修复旧图片链接

旧版本插件可能生成以下形式的图片链接：

```markdown
![IMA 图片](app://.../IMA%20Images/rich-paste-image-a983c0c8.webp?... )
```

这类地址依赖 Obsidian 当前运行环境，重启后可能失效。

插件提供全库修复功能，可以：

- 扫描仓库中的所有 Markdown 笔记；
- 识别旧的 `app://` 图片地址；
- 从旧地址中提取图片文件名；
- 在整个仓库中寻找对应图片；
- 将找到的图片改为稳定的仓库内引用；
- 找不到对应文件时保留原内容；
- 不移动、不删除图片文件。

全库修复会根据图片文件实际所在位置生成链接，因此即使后来修改了图片保存目录，也不会强行把旧图片改到新目录。

### 清理未被引用的图片

设置页的“图片维护”区域提供未引用图片清理功能。

清理前会：

- 检查当前设置中的图片保存目录；
- 扫描仓库内的 Markdown 笔记；
- 判断插件图片是否被笔记引用；
- 显示待处理的图片列表；
- 等待用户确认。

确认后，图片会移入 Obsidian 回收站，而不是直接永久删除。

使用清理功能前，建议先完成旧图片链接修复。无法确认用途的图片不要删除。

使用 `Ctrl + Z` 撤销粘贴时，插件不会自动删除已经下载的图片文件。

## 表格

插件会尽量保留以下内容：

- 行和列的数量；
- 空单元格；
- 文字所在位置；
- 部分列宽；
- 部分行高；
- 加粗、斜体、下划线和删除线；
- 字体颜色和背景高亮；
- 表格中的图片。

表格输出方式取决于当前格式：

- HTML 富格式通常使用静态 HTML 表格；
- Markdown 兼容格式会尽量转换为 Markdown 表格；
- Markdown 优先格式会在复杂表格无法安全转换时保留 HTML。

### 表格限制

HTML 表格主要用于显示，不是 Obsidian 原生的交互式表格。

因此：

- 不能像 Excel 一样直接编辑单元格；
- 不能方便地通过 Tab 键切换单元格；
- 不能直接通过表格界面增加或删除行列；
- 修改表格通常需要编辑笔记中的 Markdown 或 HTML；
- 精确列宽和行高可能受到 Obsidian 主题影响；
- 编辑模式和阅读模式中的显示效果可能不同；
- 复杂表格的部分样式无法完全还原。

Markdown 表格也有自身限制。复杂颜色、背景、图片、合并单元格和精确尺寸可能被简化。

## 公式

IMA 公式通常由独立的公式编辑器管理。

普通复制操作不一定会将公式源数据写入：

```text
application/x-ima-fragment
```

因此插件无法稳定读取和还原 IMA 公式。

当前行为可能包括：

- 公式被忽略；
- 公式内容无法粘贴；
- 无法保证 IMA 公式转换为 Obsidian MathJax 公式。

这不是 Obsidian 不支持公式，而是 IMA 普通复制时可能没有提供足够的公式源数据。

## 字体大小和行距

IMA 的复制数据不一定完整提供字号、字体、行距和间距信息。

因此：

- `h1` 至 `h6` 会转换为对应级别的 Markdown 标题；
- 没有明确字号信息的正文会使用 Obsidian 默认正文样式；
- IMA 的精确字体、字号、行距和段落间距不保证保留。

## 颜色和高亮

插件会尽量保留 IMA 提供的字体颜色和背景高亮。

支持的颜色格式包括：

- 三位十六进制颜色，例如 `#E00`；
- 六位十六进制颜色，例如 `#FA615D`；
- 八位十六进制颜色，例如 `#FFB78B8C`；
- `rgb(...)`；
- `rgba(...)`；
- `hsl(...)`；
- `hsla(...)`；
- IMA 内置颜色变量。

不透明的 `rgb(...)` 和 `rgba(...)` 颜色会尽量转换为六位十六进制颜色。

例如：

```text
rgba(244, 72, 55, 1)
```

会转换为：

```text
#F44837
```

颜色显示效果可能受到以下因素影响：

- Obsidian 当前主题；
- 编辑模式或阅读模式；
- CSS 样式覆盖；
- IMA 使用的颜色格式；
- IMA 专用颜色变量是否能够识别。

无法识别的颜色不会生成错误的 HTML，而是使用 Obsidian 默认文字颜色。

## 清理 IMA 导出内容

IMA 导出的 Markdown 中，空行有时会表现为：

```text
&#x20;
```

或：

```text
&#x20;\
```

插件提供：

```text
清理 IMA 导出空行占位符
```

命令。

该命令只处理单独占据一整行的占位符，不会删除正文中正常出现的同名字符。

## 命令

插件提供以下命令：

- 从 IMA 剪贴板粘贴；
- 转换当前笔记格式；
- 将当前笔记转换为 Markdown 兼容格式；
- 将当前笔记转换为 Markdown 优先格式；
- 修复所有笔记中的旧富文本图片地址；
- 清理 IMA 导出空行占位符。

未常用的图片维护功能也可以在插件设置的“图片维护”区域中使用。

### 从 IMA 剪贴板粘贴

当普通 `Ctrl + V` 没有自动触发时，可以通过命令面板运行：

```text
从 IMA 剪贴板粘贴
```

插件会尝试读取系统剪贴板中的 IMA 自定义数据，并将转换后的内容插入当前正文编辑器。

### 修复所有笔记中的旧富文本图片地址

该功能会扫描整个仓库的 Markdown 笔记，将能够找到对应图片文件的旧 `app://` 地址改为稳定的仓库内图片引用。

它不会移动或删除图片。

### 清理 IMA 导出空行占位符

用于清理 IMA 导出 Markdown 中单独占据一行的：

```text
&#x20;
```

或：

```text
&#x20;\
```

## 与其他粘贴插件的兼容性

如果同时使用 Paste Mode、Paste Reformatter 或其他会接管默认粘贴行为的插件，建议不要让多个插件同时处理 `Ctrl + V`。

多个插件同时处理一次粘贴，可能导致：

- 内容重复；
- 格式被二次转换；
- 图片被重复处理；
- 粘贴位置错误；
- 内容顺序异常；
- Obsidian 默认粘贴行为失效。

## 安装方式

### 方式一：使用 BRAT 安装测试版

1. 在 Obsidian 社区插件中安装并启用 BRAT。
2. 打开 BRAT 设置。
3. 添加本 GitHub 仓库：

```text
https://github.com/Curelove/obsidian-ima-enhanced-paste
```

4. 等待 BRAT 下载插件。
5. 回到 Obsidian 的第三方插件列表。
6. 启用 `IMA Enhanced Paste`。

### 方式二：手动安装

将以下文件放入当前仓库的插件目录：

```text
.obsidian/plugins/ima-enhanced-paste/
```

目录中至少需要包含：

```text
main.js
manifest.json
```

也可以包含：

```text
versions.json
```

然后：

1. 重新加载 Obsidian；
2. 打开“设置”；
3. 进入“第三方插件”；
4. 启用 `IMA Enhanced Paste`。

## 更新插件

通过 BRAT 安装的用户，可以在 BRAT 设置中检查更新。

手动更新时，将新版本文件覆盖到：

```text
.obsidian/plugins/ima-enhanced-paste/
```

更新完成后：

1. 关闭 `IMA Enhanced Paste`；
2. 再重新启用；
3. 如果没有生效，完全退出 Obsidian 后重新打开。

发布新版本时，建议同步更新：

```text
main.js
manifest.json
versions.json
README.md
GitHub Release
```

## 隐私

本插件：

- 不会将剪贴板内容上传到开发者服务器；
- 不会主动上传用户的笔记或图片；
- 普通粘贴时只读取当前粘贴事件中的剪贴板数据；
- 处理图片时会请求 IMA 图片地址；
- 会将下载的图片保存到当前 Obsidian 仓库；
- 执行全库图片修复时，会读取仓库中的 Markdown 笔记，以查找旧图片链接；
- 执行未引用图片清理时，会读取仓库中的 Markdown 笔记，以判断图片是否被引用。

图片下载需要访问 IMA 提供的图片服务器。图片 URL 通常带有临时签名参数，签名过期后可能无法下载。

## 兼容性

- Obsidian Windows 桌面版；
- 其他 Obsidian 桌面平台可能可以运行，但未进行完整测试；
- 需要 IMA 提供以下自定义剪贴板格式：

```text
application/x-ima-fragment
```

本插件依赖 IMA 的自定义剪贴板格式。如果 IMA 将来修改该格式，插件可能需要更新。

This plugin depends on IMA's custom clipboard format. Future changes to IMA may require updates to this plugin.

## 已知限制

目前无法保证完全还原的内容包括：

- IMA 公式；
- 表格的交互式编辑；
- 表格的精确列宽和行高；
- IMA 的精确字体；
- IMA 的精确字号；
- IMA 的精确行距；
- 部分复杂颜色；
- 部分自定义样式；
- 部分复杂嵌套结构；
- IMA 专属的编辑行为。

插件的目标是尽可能保留内容和结构，而不是保证与 IMA 的显示效果完全一致。

# IMA Enhanced Paste

一个用于 Obsidian 的 IMA 增强粘贴插件。

IMA 中的内容复制到 Obsidian 后，使用普通 `Ctrl + V` 有时会出现换行丢失、图片丢失或格式不完整的问题。本插件读取 IMA 提供的自定义剪贴板格式，并将其中能够识别的内容转换为 Obsidian Markdown 或 HTML。

插件会尽量保留 IMA 内容的文字、换行、基本格式、图片、列表、待办、表格和其他可识别结构。

## 功能

- 保留从 IMA 复制内容中的换行。
- 支持普通段落。
- 支持一级至六级标题。
- 支持加粗文字。
- 支持斜体文字。
- 支持下划线文字。
- 支持删除线文字。
- 支持链接。
- 支持字体颜色。
- 支持背景高亮。
- 支持左对齐、居中、右对齐和两端对齐。
- 支持无序列表。
- 支持有序列表。
- 支持待办事项和已完成待办事项。
- 支持代码块。
- 支持引用内容。
- 支持 IMA 分隔线。
- 支持 IMA 表格的结构化粘贴。
- 支持文字与图片混合粘贴。
- 自动下载 IMA 中的图片并保存到当前仓库。
- 相同图片再次粘贴时会复用已有文件，避免重复下载。
- 支持将纯文字 IMA 内容粘贴到 Obsidian 内联标题。
- 在正文中有选中文字时，会使用 IMA 内容替换选区。
- 在没有选中文字时，会将内容插入当前光标位置。
- 仅在检测到 IMA 自定义剪贴板格式时接管粘贴。
- 从网页、记事本、Word 或其他软件复制时，继续使用 Obsidian 原本的粘贴行为。
- 提供清理 IMA 导出 Markdown 空行占位符的命令。

## 使用方法

1. 在 IMA 中选中需要复制的内容。
2. 按 `Ctrl + C`。
3. 打开 Obsidian 中的 Markdown 笔记。
4. 将光标放在需要插入内容的位置。
5. 按 `Ctrl + V`。

如果剪贴板中包含 IMA 的自定义格式，插件会自动转换内容并插入当前笔记。

如果剪贴板中不包含 IMA 自定义格式，插件不会干预，Obsidian 会继续使用默认粘贴功能。

## 粘贴位置

### 粘贴到正文

将内容粘贴到 Obsidian 正文编辑区时：

- IMA 文字会转换为 Obsidian Markdown；
- 图片会下载到仓库中的 `IMA Images` 文件夹；
- 选中文字会被粘贴内容替换；
- 未选中文字时，内容会插入光标位置；
- 标题、列表、待办、分隔线、代码块和引用会尽量转换。

### 粘贴到内联标题

将纯文字 IMA 内容粘贴到 Obsidian 内联标题时：

- 内容会插入标题输入区域；
- 图片会被忽略；
- 表格、代码块、复杂格式和其他非纯文字内容不会作为标题内容插入。

需要注意，Obsidian 内联标题和正文中的 Markdown 标题不是同一个编辑区域。

### 粘贴到笔记属性

粘贴到 Obsidian 笔记属性区域时：

- 本插件不会接管粘贴；
- 内容会交给 Obsidian 默认处理；
- 不会强行将内容插入正文。

## 支持的格式

IMA 内容会尽量转换成 Obsidian Markdown 或兼容 Obsidian 的 HTML：

| IMA 格式 | 转换结果 |
| --- | --- |
| 普通文字 | 普通文字 |
| 加粗 | `**加粗文字**` 或 HTML 加粗 |
| 斜体 | `*斜体文字*` 或 HTML 斜体 |
| 加粗并斜体 | `***文字***` |
| 下划线 | `<u>下划线文字</u>` |
| 删除线 | `~~删除线文字~~` 或 HTML 删除线 |
| 字体颜色 | `<span style="color: ...">文字</span>` |
| 背景高亮 | `<mark style="background-color: ...">文字</mark>` |
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 三级标题 | `### 标题` |
| 无序列表 | `- 列表内容` |
| 有序列表 | `1. 列表内容` |
| 未完成待办 | `- [ ] 待办内容` |
| 已完成待办 | `- [x] 已完成内容` |
| 分隔线 | `---` |
| 代码块 | Markdown 代码块 |
| 引用 | `> 引用内容` |
| 链接 | `[链接文字](https://example.com)` |
| 表格 | HTML 静态表格 |
| 图片 | 下载到本地后插入 |

## 图片

IMA 中的图片会尝试下载到当前 Obsidian 仓库根目录下的：

```text
IMA Images
```

图片下载成功后，笔记中会插入本地图片链接。

同一张图片再次从 IMA 复制并粘贴时，插件会根据图片的稳定地址生成相同文件名，并复用已有图片，避免重复下载。

图片文件名通常类似：

```text
ima-image-a1b2c3d4.webp
```

如果图片链接已经过期、签名失效或服务器拒绝访问，插件会尽量保留临时网络图片链接。临时网络链接可能会在之后失效。

使用 `Ctrl + Z` 撤销粘贴时，插件不会自动删除已经下载的图片文件。这样可以避免误删仍然被其他笔记使用的图片。未被引用的旧图片需要手动清理。

## 表格

插件会尽量保留 IMA 表格的以下内容：

- 行和列的数量；
- 空单元格；
- 文字在表格中的位置；
- 部分列宽；
- 部分行高；
- 加粗；
- 斜体；
- 下划线；
- 删除线；
- 字体颜色；
- 背景高亮；
- 表格中的图片。

为了尽量保留这些效果，IMA 表格会转换为 HTML 表格，而不是普通 Markdown 表格。

### 表格的限制

粘贴后的表格主要用于显示，不是 Obsidian 原生的交互式表格。

因此：

- 不能像 Excel 一样直接点击单元格编辑；
- 不能方便地通过 Tab 键切换单元格；
- 不能直接通过表格界面增加或删除行列；
- 修改表格通常需要编辑 Markdown 文件中的 HTML 代码；
- 表格的精确列宽和行高可能受到 Obsidian 主题影响；
- 编辑模式和阅读模式中的显示效果可能不同；
- 某些复杂的 IMA 表格样式无法完全还原。

插件会尽量保留：

- 表格的行数和列数；
- 空单元格；
- 单元格所在位置；
- 部分列宽；
- 部分行高；
- 加粗、斜体、下划线和删除线；
- 字体颜色；
- 背景高亮；
- 表格中的图片。

粘贴表格时，插件会提示：

```text
表格已尽量保留，但在 Obsidian 中为静态 HTML 表格，不能像原生表格一样直接交互编辑
```

如果需要交互编辑普通 Markdown 表格，可以尝试使用 Obsidian 社区插件 `Advanced Tables`。

但是，`Advanced Tables` 主要用于 Markdown 表格，不能完整编辑本插件生成的 HTML 表格。如果改用 Markdown 表格，可能需要放弃部分颜色、背景高亮和复杂格式。

## 公式

IMA 中的公式通常使用独立的公式编辑器保存。

公式不是普通文本光标可以直接进入的内容。点击公式后，IMA 会弹出单独的公式编辑窗口，用户在窗口中修改公式内容，修改结果再以特殊方式显示在正文中。

普通复制操作通常不会将公式的实际内容写入：

```text
application/x-ima-fragment
```

因此插件无法稳定读取和还原 IMA 公式。

当前行为：

- 公式可能不会被粘贴；
- 公式内容可能被忽略；
- 插件不会凭空生成公式内容；
- 无法保证 IMA 公式能够转换为 Obsidian MathJax 公式。

这不是 Obsidian 不支持公式，而是 IMA 普通复制时没有提供足够的公式源数据。

## 字体大小和行距

IMA 中的不同正文样式和标题样式可能包含不同字号、行距和间距。

但是，IMA 的复制数据不一定会完整提供这些视觉信息，或者不同样式可能被记录为相同的节点类型。

例如：

- IMA 中的“标题”和“标题 1”可能都被记录为 `h1`；
- IMA 中的“正文 1”“正文 2”“正文 3”可能没有明确的字号信息；
- 插件无法仅根据内容推断原始字号；
- IMA 的精确行距和段落间距无法完全还原。

因此：

- `h1`、`h2`、`h3` 会转换为 Obsidian 对应级别的标题；
- 没有明确字号信息的正文会使用 Obsidian 默认正文样式；
- IMA 的精确字体、字号和行距不保证保留。

## 颜色和高亮

插件会尽量保留 IMA 提供的字体颜色和背景高亮。

支持的颜色格式包括：

- 六位十六进制颜色，例如 `#FA615D`；
- 三位十六进制颜色，例如 `#E00`；
- 八位十六进制颜色，例如 `#FFB78B8C`；
- `rgb(...)`；
- `rgba(...)`；
- `hsl(...)`；
- `hsla(...)`；
- IMA 内置颜色变量。

不透明的 `rgb(...)` 或 `rgba(...)` 颜色会尽量转换为六位十六进制颜色，以提高 Obsidian 中的显示兼容性。

例如：

```text
rgba(244, 72, 55, 1)
```

会转换为：

```text
#F44837
```

字体颜色会转换为：

```html
<span style="color:#F44837;">文字</span>
```

背景高亮会转换为：

```html
<mark style="background:#FA615D;">文字</mark>
```

字体颜色和背景颜色可以同时存在。

最终显示效果可能受到以下因素影响：

- Obsidian 当前主题；
- 编辑模式或阅读模式；
- CSS 样式覆盖；
- IMA 使用的颜色格式；
- 颜色是否为 IMA 专用 CSS 变量。

插件会保留能够识别的颜色。无法识别的颜色不会生成错误的 HTML，而是使用 Obsidian 默认文字颜色。

## 清理 IMA 导出内容

IMA 导出的 Markdown 中，空行有时会表现为：

```text
&#x20;
```

或：

```text
&#x20;\
```

本插件提供了：

```text
清理 IMA 导出空行占位符
```

命令。

该命令可以将单独占据一整行的 IMA 空行占位符转换为空行。

该命令不会删除正文中正常出现的同名字符。

## 命令

插件目前提供以下命令：

- 从 IMA 剪贴板粘贴
- 清理 IMA 导出空行占位符

### 从 IMA 剪贴板粘贴

当普通 `Ctrl + V` 没有自动触发时，可以通过命令面板运行：

```text
从 IMA 剪贴板粘贴
```

该命令会尝试读取系统剪贴板中的 IMA 自定义数据，并将转换后的内容插入当前正文编辑器。

### 清理 IMA 导出空行占位符

用于清理 IMA 导出 Markdown 中单独占据一行的：

```text
&#x20;
```

或：

```text
&#x20;\
```

## 与其他粘贴插件的兼容性

如果同时使用 Paste Mode、Paste Reformatter 或其他会接管默认粘贴行为的插件，建议不要让多个插件同时处理 `Ctrl + V`。

测试本插件时，建议暂时关闭其他插件的默认粘贴接管功能。

多个插件同时处理一次粘贴操作，可能导致：

- 内容重复；
- 格式被二次转换；
- 图片被重复处理；
- 粘贴位置错误；
- 粘贴内容顺序异常；
- Obsidian 默认粘贴行为失效。

## 安装方式

### 方式一：使用 BRAT 安装测试版

1. 在 Obsidian 社区插件中安装并启用 BRAT。
2. 打开 BRAT 设置。
3. 添加本 GitHub 仓库：

```text
https://github.com/Curelove/obsidian-ima-enhanced-paste
```

4. 等待 BRAT 下载插件。
5. 回到 Obsidian 的第三方插件列表。
6. 启用 `IMA Enhanced Paste`。

### 方式二：手动安装

将以下文件放入当前仓库的插件目录：

```text
.obsidian/plugins/ima-enhanced-paste/
```

目录中需要包含：

```text
main.js
manifest.json
```

如果使用 BRAT 或版本兼容检查，也可以包含：

```text
versions.json
```

然后：

1. 重新加载 Obsidian；
2. 打开“设置”；
3. 进入“第三方插件”；
4. 启用 `IMA Enhanced Paste`。

## 更新插件

通过 BRAT 安装的用户，可以在 BRAT 设置中检查更新。

手动更新时，将新的文件覆盖到：

```text
.obsidian/plugins/ima-enhanced-paste/
```

更新完成后：

1. 关闭 `IMA Enhanced Paste`；
2. 再重新启用；
3. 如果没有生效，完全退出 Obsidian 后重新打开。

每次发布新版本时，建议同步更新：

```text
main.js
manifest.json
versions.json
GitHub Release
```

## 隐私

本插件：

- 不会将剪贴板内容上传到开发者服务器；
- 不会主动读取整个 Obsidian 仓库的笔记内容；
- 只在粘贴操作发生时读取 IMA 自定义剪贴板数据；
- 在遇到 IMA 图片时，会请求 IMA 图片地址；
- 会将下载到的图片写入当前 Obsidian 仓库的 `IMA Images` 文件夹；
- 不会主动上传用户的笔记或图片。

IMA 图片下载需要访问 IMA 提供的图片服务器。图片 URL 通常带有临时签名参数，签名过期后可能无法下载。

## 兼容性

- Obsidian Windows 桌面版；
- 其他 Obsidian 桌面平台可能可以运行，但未进行完整测试；
- 需要 IMA 提供以下自定义剪贴板格式：

```text
application/x-ima-fragment
```

本插件依赖 IMA 的自定义剪贴板格式。如果 IMA 将来修改该格式，插件可能需要更新。

This plugin depends on IMA's custom clipboard format. Future changes to IMA may require updates to this plugin.

## 已知限制总结

目前无法保证完全还原的内容包括：

- IMA 公式；
- 表格的交互式编辑；
- IMA 表格的精确列宽和行高；
- IMA 的精确字体；
- IMA 的精确字号；
- IMA 的精确行距；
- 部分复杂颜色；
- 部分自定义样式；
- 部分复杂嵌套结构；
- IMA 专属的编辑行为。

插件的目标是尽可能保留内容和结构，而不是保证与 IMA 的显示效果完全一致。
